# Todo App

A simple TODO list application: view your items, add new ones, and delete them.
## Prerequisites

- [.NET SDK 10](https://dotnet.microsoft.com/download)
- [Node.js](https://nodejs.org/) 20+ and npm
- Angular CLI (`npm install -g @angular/cli`)

## Running the app


Open `Todo-App.slnx`, set **Todo-App.Server** as the startup project, and run (F5). Visual
Studio's SPA proxy automatically starts the Angular dev server for you and opens the app in your
browser.
